# Protein Structure Classification Model

This component contains the machine learning model for classifying proteins based on their structural scores.

## Directory Structure

- `src/`: Source code for the classification model
- `data/`: Data directory for training and testing
  - `raw/`: Raw score files
  - `processed/`: Processed datasets
- `models/`: Trained model files and checkpoints
- `tests/`: Unit tests
